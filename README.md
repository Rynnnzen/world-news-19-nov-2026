that sums up the day's world news at a glance. The masthead reads
"WORLD NEWS" over a red "19 NOVEMBER 2026" dateline, and four panels
carry the day's biggest stories: the trilateral summit in Shenzhen
bringing Trump, Xi and Putin to the same table; the International
Court of Justice ruling on the Rohingya case; Cyclone Akvan making
landfall; and Anthropic's record-breaking $81.3B IPO. A footer ticker
rounds out the day with the Crimea bridge being hit again, the COP31
deadlock, and the launch of GTA VI — so anyone who missed the day can
still tell what happened from this one image alone.

This is an entry for the [make.fun](https://make.fun/?ref=3nca7vjq&utm_source=github&utm_medium=readme&utm_campaign=news-image-20261119)
news-image-20261119 bounty: sum up 19 November's world news in one image.

## Run it

```sh
python3 main.py
```

That writes the front page to `/output/entry.png`. To write it
somewhere else instead:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program needs nothing but the Python standard library — no
network, no extra packages, no clock, no randomness. It copies the
finished image from `assets/entry.png` byte for byte, so every run
produces the exact same file: a 1024x1024 image, 297,249 bytes, under
the competition's 1 MiB cap.
